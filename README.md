# Nightly 尝鲜版

绝区零一条龙第三方插件：一键把代码源切到 idk500 增强源的 **nightly** 分支，无需手动编辑配置文件。

## 这是什么

官方版发布节奏稳，但社区里很多改动等不到合入。**Nightly 是给愿意先试的人用的通道**：跑得比官方快半步，代价是稳定性不承诺。

## 定位与吸纳策略

- **基座每月一班车**：基座每月更新一班车（发车前过全链回归），插件随时更新。
- **尽力吸纳社区提交**：功能类、修复类、体验类 PR 一律先合进来试用，不因为"还不够完美"就卡着。
- **但保留审核底线**，以下三类先评估再合，不盲合：
  1. 破坏性变更（删配置项、改数据结构、动插件接口）—— 需要迁移方案；
  2. 涉及游戏安全与账号风险的改动（自动化点击范围、请求频率、登录凭据处理）；
  3. 无法在本地复现或无法验证效果的改动 —— 先挂起等作者补证据。

换句话说：**门槛低，但不是没有门槛**。被拒的提交会在对应 PR 里说明原因，不会静默消失。

## 使用

1. 将本仓库 Release 的 zip 导入主程序「资源管理 → 插件管理」，或解压到主程序 `plugins/nightly/`；
2. 重启后运行工具列表中的「Nightly 尝鲜版」；
3. 按提示重启一条龙，之后自动从 nightly 分支更新代码。

已切到 nightly 时再运行会直接提示无需重复切换。

> 早先装过 ZODE 切换器、代码源还绑在 `zode` 分支上的，直接运行本插件即可自动迁移到 `nightly`。

## 回到官方版

「资源管理 → 代码源」切回官方源（GitHub / Gitee / CNB）+ `main` 分支，再同步一次即可。插件只改配置，不会留下需要清理的残留。

## 声明

仅修改 `config/repository.yml`（代码源声明）与 `config/env_config.yml`（用户选择），不进行任何游戏画面操作。
